沙田:乜嘢條件容易贏 / 入位?

115,605 匹次出賽記錄(2008–2026,9,082 場沙田賽事)嘅拆解。每個特徵計「賽果率」 同「lift」—— lift > 1 即係贏 / 入位機會高過隨機期望,lift < 1 即係低過期望。

沙田 ST 全期115,605 匹次賽果率 = 勝率 / 上名率基準 lift = 1.00

易贏 / 易入位嘅「標準樣」

  • 近況:近 3 仗平均名次 ≤ 4,上仗跑入前 3(上仗贏 → 勝率 18% / 上名 43%)
  • 生涯:第 5–15 次出賽嘅上進馬,或者生涯上名率 > 45%;避開 25 戰以上嘅老馬
  • 年資:來港 0.5–1.5 年嘅新馬(勝率 lift 1.18);來港 4 年以上明顯回落
  • 今仗安排:同上仗一樣路程(lift 1.18),檔位 1–5(尤其 1200–1650m),習慣前領 / 爭先跑法
  • 負磅:負磅高過全場平均(高分頂磅馬,係實力代理,唔係因果)
  • 休息:上仗距今 22–42 日;避開 < 14 日速戰同 > 180 日長抖
  • 沙田經驗:跑過沙田 5 次以上,跑過呢個路程 3 次以上
  • 騎師:一線騎師(勝率 > 14% → 勝率 17–21% / 上名 40–47%),最好曾策同一匹馬入位,而且騎練拍檔往績夾
  • 唔使理:場地狀況 going、月份、欄位 rail、草地定全天候 —— 對「邊隻馬贏」零預測力

一、賽事條件race setup — draw / style / weight / going

檔位(絕對檔號)

檔位 → 勝率 / 上名率 / lift
檔位匹次勝率上名率入位 lift　

內檔優勢明確:1 檔勝率 10.2% / 上名 29%(lift 1.26 / 1.21),12 檔外只得 6.6% / 19%。 但呢個係結構性偏差,唔係「執靚」—— 每個馬迷都知,賠率已經反映咗大半。

檔位 × 路程(上名率 %)

內檔優勢喺 1200–1650m 最勁(內檔 1-3 上名 27–30% vs 極外 19%)。 但 1000m 直路飛反轉 —— 內檔 1-3 只得 20% 上名,仲低過極外檔(26%),因為短途爆閘埋欄嘅動態唔同。

跑法(習慣前置位)

跑法 → 賽果率 / lift
跑法匹次勝率上名率入位 lift　

沙田利前領馬:習慣爭先嘅馬上名 29.6%(lift 1.24),後上馬得 21%(lift 0.90)。 前領優勢喺 1000–1400m 最大(上名 29–32%),要到 1800m 以上後上馬先追得返。 落雨扑爛地都唔改變呢個規律。

負重(相對全場平均)

負磅匹次勝率上名率入位 lift　
負磅高 ≠ 因果。 頂磅馬贏得多(重 > 6 磅 → 勝率 9.9%),係因為佢哋評分高、實力強先要孭咁重。 呢個係班次 / 實力嘅代理指標,唔係「孭多啲會跑快啲」。

場地狀況、欄位、路程、月份

全部 lift ≈ 1.00 —— going(GOOD / GOOD TO FIRM / 扑爛地…)、rail(A / B / C / +3)、 路程(1000–2400m)、月份,對「邊隻馬贏 / 入位」冇任何馬匹層面嘅預測力。 天氣同場地影響嘅係跑法同檔位嘅價值(見上),唔係邊隻馬。

四、模型排名LightGBM gain — 控制晒其他變數之後,邊個特徵真係有預測力

預測「入位」嘅特徵重要性(gain %)。近 3 仗平均名次獨佔 25%,加埋上仗名次共 ~32% 係「近況」。 騎師相關(勝率 + 上名率 + 拍檔)合共 ~21%。檔位得 2.5%,路程 / going / 月份合共 < 4% —— 知道匹馬近況同邊個踢之後,賽事條件加唔到幾多資訊。

五、要記住嘅陷阱

  • 呢啲係「乜嘢會贏」,唔係「乜嘢抵買」。 一匹樣樣綠燈嘅馬會係大熱,賠率已經反映, 17.5% 抽水照食。要贏錢係要搵市場低估咗嘅綠燈組合。
  • 特徵之間高度相關:近況好 → 通常頂磅、一線騎師、內檔被追捧。唔好重複計分。
  • 負磅、班次高 = 實力代理,唔係因果。
  • 細樣本格(2200m+、極端拍檔率、老馬)數字波幅大,當參考唔好當定律。
  • 天氣 / going 唔影響「邊隻馬」,但放大咗前領馬同內檔嘅價值 —— 落雨爛地更加要跟前領內檔。
